# Segurança

Não publique tokens, credenciais, perfis de navegador ou conversas pessoais em issues.

Se um problema permitir acesso indevido aos arquivos ou ao serviço local, evite publicar instruções de exploração e dados sensíveis. Use a opção de relato privado do GitHub quando estiver disponível; caso contrário, abra uma issue mínima solicitando um canal privado para os detalhes.

Esta versão experimental foi validada em Windows x64 e Ubuntu 26.04 x64 via WSL. As orientações upstream estão preservadas em docs/upstream-metadata/SECURITY.md.
