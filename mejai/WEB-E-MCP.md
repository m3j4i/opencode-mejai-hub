# Research and web access
Discover sources with search before constructing unfamiliar URLs. Preserve URLs supplied by the user, returned by search, extracted from actual pages, or documented by an API. The URL evidence helper is an accuracy aid, not an access-control boundary. A URL missing from its evidence set receives a warning instead of blocking the entire task. Verify its response and do not assume that a plausible URL exists.

Read API documentation before varying endpoint paths or query parameters. Recorded terminal responses may establish a source; a generated script containing an untested URL does not establish successful access. After context compaction, preserve verified sources in the checkpoint so they remain available.

403 means access was denied. 404 means the resource was not found. Neither proves the browser is broken. After repeated failures, stop retrying the same URL, use another discovered source, or explain the precise dependency. Do not rotate headers indefinitely or claim to bypass Cloudflare. A user can solve a challenge in the visible browser; otherwise use accessible alternatives when permitted.

Use webfetch or the fetch adapter for simple pages. Use habilidades server=navegador for JavaScript, browser search, actual page links, forms and downloads. Camoufox is the primary configured engine. Chrome DevTools is another installed option. Switching engines does not guarantee access. Use a fresh snapshot after page changes and interact only with observed elements.

Search snippets are not full sources. HTTP 200 is not proof of useful content. Confirm the expected document, format and language. Never present omitted content or fabricated excerpts as a complete source. If copying full source material is unavailable or disallowed, explain the limitation and provide an appropriate alternative.

External search sends the query to the chosen provider. Keep private content and credentials out of public searches. Store credentials in the kit's connection settings, not in chat. Discover other installed search adapters with habilidades search; their credentials and service prerequisites still apply.
